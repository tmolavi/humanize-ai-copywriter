## ⚡ لماذا قمنا ببناء Humanize-AI-Copywriter؟

تفشل معظم النصوص الإعلانية والمقالات المولدة بالذكاء الاصطناعي للأسباب التالية:
١. **تبدو آلية وغير طبيعية**: استخدام عبارات مكررة ومعقدة دون فائدة ونمط كتابي متطابق يثير شكوك العملاء ويكتشفه كواشف الذكاء الاصطناعي (Turnitin، GPTZero، Originality.ai).
٢. **لا تقنع القارئ بالشراء**: تركز على سرد الخصائص التقنية بدلاً من معالجة أوجاع العميل الحقيقية وتقديم حلول ملموسة وواضحة.
٣. **تفشل في الظهور في محركات البحث الذكية (GEO)**: إما تركز فقط على حشو الكلمات المفتاحية لجوجل التقليدي، أو تفتقر للجمل والفقرات المستقلة المباشرة التي تحتاجها أنظمة مثل Perplexity و ChatGPT Search.

يقدم هذا المشروع مهارة وكلاء مفتوحة المصدر تتبع **مبدأ الانتروبيا الصفرية ($H \to 0$)**، **استنساخ الأسلوب والنبرة البشرية من الروابط (Voice Cloning)**، **تغيير إيقاع الجمل الحاد (Burstiness)**، و**هندسة الإقناع التسويقي**.

## 🚀 التثبيت والاستخدام السريع

```bash
git clone https://github.com/tmolavi/humanize-ai-copywriter.git
cd humanize-ai-copywriter
pip install -e .
```

### فحص مسودة والتحقق من بصمة الذكاء الاصطناعي

```bash
humanize-ai-copywriter audit ./draft.md
```

### استنساخ نبرة صوت الموقع أو المقال

```bash
humanize-ai-copywriter clone-voice https://molavi.pro/research
```
