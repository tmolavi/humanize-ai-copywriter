## ⚡ Why Humanize-AI-Copywriter Exists

Most AI-generated marketing copy fails in production for three interconnected reasons:
1. **It Sounds Synthetic & Robotic**: It reeks of ChatGPT clichés (*delve, tapestry, pivotal, rapidly evolving landscape*) and uniform sentence pacing that instantly triggers customer skepticism and flags AI detection tools (Turnitin, GPTZero, Originality.ai).
2. **It Doesn't Sell**: It talks about features rather than visceral pain points, hides behind polite passive voice, and makes vague claims without empirical proof.
3. **It Fails Dual Search Discovery**: It either stuffs keywords for traditional Google crawlers and gets ignored by AI engines (Perplexity, ChatGPT Search, Gemini Grounding), or writes conversational fluff with zero passage-level citability.

**Humanize-AI-Copywriter** is an open-source, universal agent skill and CLI tool built to solve all three at once: **Zero-Entropy Information Architecture ($H \to 0$)**, **Empirical Voice Cloning**, **100% Undetectable Human Burstiness**, and a **Neuromarketing Arc** engineered to convert readers into buyers.

## 🎯 Core Capabilities & Workflow

```text
User Input & Intent Discovery ──▶ Few-Shot Voice Cloning ──▶ Dual SEO & GEO Architecture ──▶ Zero-Entropy Scrub ──▶ 100% Human Sales Output
 (Pain, Audience, Offer)          (URL / Sample Ingestion)    (AEO Hook + RAG FAQs)         (Purge Fluff & Tells)     (Bypasses All Detectors)
```

1. **User Intent Discovery**:
   - **Default Mandate**: Persuasive commercial conversion (selling physical goods, digital products, or professional services).
   - **Flexible Override**: The user can easily switch the primary intent to technical education, thought leadership, neutral journalistic briefing, or brand authority.
2. **Few-Shot Voice Cloning**:
   - Provide one or more URLs or sample articles. The engine parses syntactic cadence, punctuation preferences, sentence length distribution, and vocabulary habits to clone the brand's authentic voice.
3. **Zero-Entropy Writing Paradigm ($H \to 0$)**:
   - Rooted in Shannon information theory: maximum substantive signal, zero throat-clearing intro fluff (*"In this article we will..."*), and zero redundant adjectives. Every word delivers unique informational or transactional weight.
4. **Dual SEO & GEO/AEO Citations**:
   - Injects a standalone, unambiguous 25–40 word AEO extraction sentence directly beneath the H1 for AI search engines.
   - Generates sub-50-word FAQ chunks optimized for Large Language Model RAG retrieval and Google Rich Snippets.
5. **100% Undetectable Humanization**:
   - Enforces radical **Burstiness** (asymmetric variation between 2-word punches and 30-word compound arguments).
   - Strict ban on 21 categories of machine tells and 43 blacklisted AI clichés.

## 🚀 Quick Start & CLI Usage

### Installation

```bash
git clone https://github.com/tmolavi/humanize-ai-copywriter.git
cd humanize-ai-copywriter
pip install -e .
```

### 1. Audit an Existing Draft for AI Fingerprints

```bash
humanize-ai-copywriter audit ./draft.md
```

Outputs a terminal scorecard displaying:
- **Burstiness (Sentence Variance)**: Minimum pass $\ge 0.35$.
- **Predicted Human Score**: $\ge 90\%$.
- **AI Cliché Detections**: Flagged terms and mandatory plain replacements.
- **Lexical Density & Entropy**: Minimum pass $\ge 52\%$.

### 2. Generate a Complete Dual SEO/GEO Copy Plan

```bash
humanize-ai-copywriter plan \
  --topic "PostgreSQL High-Concurrency Migrations" \
  --audience "Senior Backend Engineers" \
  --product "pg-teleport" \
  --intent "commercial-sale" \
  --sample-url "https://your-brand-domain.com/blog/sample-post" \
  --out ./agent-prompt.md
```

### 3. Clone Voice from a Website or Article

```bash
humanize-ai-copywriter clone-voice https://molavi.pro/research
```
