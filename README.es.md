## ⚡ ¿Por qué existe Humanize-AI-Copywriter?

La mayoría de los textos de marketing generados por inteligencia artificial fracasan en producción por tres razones:
1. **Suenan mecánicos y robóticos**: El uso de clichés (*delve, tapestry, pivotal, paisaje en rápida evolución*) y longitudes de oración uniformes generan desconfianza inmediata en el comprador y activan detectores de IA (Turnitin, GPTZero, Originality.ai).
2. **No venden**: Se enfocan en características técnicas en lugar de los puntos de dolor reales del cliente, con llamadas a la acción (CTA) tímidas y genéricas.
3. **Fracasan en la búsqueda generativa (GEO)**: Ignoran la arquitectura de extracción que necesitan motores como Perplexity, ChatGPT Search o Google AI Overviews.

**Humanize-AI-Copywriter** resuelve estos problemas combinando **Entropía Cero ($H \to 0$)**, **Clonación de Voz de Marca (Voice Cloning)**, **Variación Asimétrica de Ritmo (Burstiness)** y un **Arco de Neuromarketing** diseñado para convertir visitas en ventas.

## 🚀 Instalación y Uso Rápido

```bash
git clone https://github.com/tmolavi/humanize-ai-copywriter.git
cd humanize-ai-copywriter
pip install -e .
```

### 1. Auditar un Borrador para Detectar Huellas de IA

```bash
humanize-ai-copywriter audit ./borrador.md
```

### 2. Clonar la Voz de Marca desde una URL

```bash
humanize-ai-copywriter clone-voice https://molavi.pro/research
```
