## ⚡ چرا Humanize-AI-Copywriter ساخته شد؟

بیشتر متونی که با هوش مصنوعی برای بازاریابی و فروش نوشته می‌شوند در دنیای واقعی با شکست مواجه می‌شوند؛ به ۳ دلیل مشخص:
۱. **بوی هوش مصنوعی می‌دهند و بی‌روح هستند**: عبارات نخ‌نما و متظاهرانه‌ای مثل «در دنیای پرشتاب امروز»، «نقش بسزایی دارد»، «سفری شگفت‌انگیز» و جملاتی با طول‌های اتوکشیده و یکنواخت، باعث بی‌اعتمادی فوری خریدار و اخطار ابزارهای تشخیص هوش مصنوعی (GPTZero، Turnitin، Originality.ai) می‌شوند.
۲. **نمی‌فروشند**: به جای انگشت گذاشتن روی درد واقعی و ملموس مشتری، پشت واژه‌های پرطمطراق و ویژگی‌های فنی پنهان می‌شوند و کال‌تو‌اکشن (CTA) مبهم و ترسو ارائه می‌دهند.
۳. **در جستجوی نوین (GEO) شکست می‌خورند**: یا برای گوگل سنتی کلمات کلیدی را چپاول می‌کنند و هوش‌های مصنوعی (Perplexity، ChatGPT، Gemini) آن را نادیده می‌گیرند، یا انشای طولانی می‌نویسند که هیچ پاراگراف مستقل و قابل استخراجی ندارد.

پروژه **Humanize-AI-Copywriter** یک اسکیل چندعاملی (Universal Agent Skill) و ابزار خط فرمان متن‌باز است که این ۳ مسئله را هم‌زمان با **معماری آنتروپی صفر ($H \to 0$)**، **شبیه‌سازی لحن زنده (Voice Cloning)**، **ایجاد تنوع ساختاری ناگهانی (Burstiness)** و **آرک نورومارکتینگ فروش** حل می‌کند.

## 🎯 شیوه کار و فرآیند گام‌به‌گام

```text
کشف نیت و ورودی ──▶ شبیه‌سازی لحن اختصاصی ──▶ معماری دوگانه SEO و GEO ──▶ پالایش آنتروپی صفر ──▶ خروجی ۱۰۰٪ انسانی و پرفروش
(درد، مخاطب، محصول)      (دریافت لینک / مقاله نمونه)     (قلاب AEO + پاسخ‌های RAG)       (حذف کلیشه‌ها و پرتی)        (دور زدن تمام دتکتورها)
```

۱. **کشف نیت کاربر (User Intent Discovery)**:
   - **هدف پیش‌فرض**: ترغیب ملموس به خرید کالا یا خدمت (Commercial Conversion).
   - **تغییر منعطف هدف**: کاربر می‌تواند در صورت تمایل هدف را روی آموزش فنی، مرجعیت برند، نگارش بی‌طرفانه تحلیلی یا مقاله فکری تنظیم کند.
۲. **شبیه‌سازی لحن بر اساس نمونه‌ها (Few-Shot Voice Cloning)**:
   - کافی است یک یا چند لینک وب‌سایت یا مقالات قبلی خود را به ابزار بدهید. این اسکیل ریتم جملات، نحوه نگارش، علائم نگارشی و دایره واژگان خاص شما را استخراج و در نگارش شبیه‌سازی می‌کند.
۳. **پارادایم نگارش با آنتروپی صفر ($H \to 0$)**:
   - مبتنی بر نظریه اطلاعات شانون: حداکثر سیگنال مفید و حداقل نویز. حذف کامل مقدمه‌های کش‌دار و توخالی («در این مقاله قصد داریم...»). هر کلمه دارای بار معنایی یا محرک فروش است.
۴. **استخراج دوگانه در گوگل (SEO) و هوش مصنوعی (GEO/AEO)**:
   - قرار دادن یک جمله مستقل و بدون ابهام ۲۵ تا ۴۰ کلمه‌ای بلافاصله پس از عنوان اصلی (H1) که به پرسش «این محصول چیست؟» پاسخ می‌دهد و خزنده‌های هوش مصنوعی مستقیماً آن را نقل‌قول می‌کنند.
   - تولید پرسش و پاسخ‌های بهینه‌شده زیر ۵۰ کلمه برای استفاده در سیستم‌های RAG و پاسخ‌های سریع گوگل.
۵. **انسانی‌سازی ۱۰۰٪ و غیرقابل تشخیص**:
   - اعمال قانون تفاوت شدید طول جملات (یک جمله ۲ کلمه‌ای در کنار جمله‌ای ۳۰ کلمه‌ای با استدلال فنی).
   - حذف کامل ۲۱ دسته از ردپاهای ماشینی و ۴۳ اصطلاح تکراری و مصنوعی هوش مصنوعی.

## 🔬 جدول مقایسه روش‌شناسی

| بعد ارزیابی | کپی‌رایتینگ متداول هوش مصنوعی | آژانس‌های سئوی سنتی | متدولوژی Humanize-AI-Copywriter |
| :--- | :--- | :--- | :--- |
| **آنتروپی اطلاعاتی** | بالا ($H > 4.5$) — پر از کلمات حشو | متوسط — پر از کلمات کلیدی تکراری | **آنتروپی صفر ($H \to 0$)** — سیگنال خالص |
| **ریتم و شاخص Burstiness** | صاف و یکنواخت ($< 0.25$) | ساختار یکنواخت و کسل‌کننده | **نوسان بالا ($> 0.45$)** — ریتم زنده انسانی |
| **استناد هوش مصنوعی (GEO)** | کاملاً نادیده گرفته می‌شود | فاقد ساختار استخراج RAG | **بلوک استخراج ۲۵-۴۰ کلمه‌ای اختصاصی AEO** |
| **ترغیب و فروش** | جملات پندآموز، بدون CTA واقعی | فقط به دنبال ترافیک با لید پایین | **درد مشتری $\leftarrow$ اثبات $\leftarrow$ جدول مزیت $\leftarrow$ اقدام صریح** |
| **شبیه‌سازی لحن برند** | لحن کلیشه‌ای و عمومی چت‌بات | مقیاس‌پذیری سخت و زمان‌بر | **شبیه‌ساز مستقیم از URL یا متن با روش Few-Shot** |

## 🚀 راهنمای نصب و استفاده از ابزار خط فرمان (CLI)

### نصب سریع

```bash
git clone https://github.com/tmolavi/humanize-ai-copywriter.git
cd humanize-ai-copywriter
pip install -e .
```

### ۱. ارزیابی یک متن از نظر ردپای هوش مصنوعی و آنتروپی

```bash
humanize-ai-copywriter audit ./draft.md
```
این دستور جدولی کامل از شاخص Burstiness، نمره پیش‌بینی انسانی، عبارات ماشینی شناسایی‌شده و جایگزین‌های آن ارائه می‌دهد.

### ۲. تدوین نقشه محتوای پرفروش و سئو/GEO

```bash
humanize-ai-copywriter plan \
  --topic "مهاجرت دیتابیس پستگرس بدون قطعی" \
  --audience "توسعه‌دهندگان ارشد بک‌اند" \
  --product "pg-teleport" \
  --intent "commercial-sale" \
  --sample-url "https://molavi.pro/research" \
  --out ./agent-prompt.md
```

### ۳. استخراج لحن یک وب‌سایت یا مقاله

```bash
humanize-ai-copywriter clone-voice https://molavi.pro/research
```
